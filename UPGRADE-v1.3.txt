CHAMPIONS BOLÃO — ATUALIZAÇÃO v1.3

Se seu banco já executou o setup.sql da v1.2:
- NÃO é necessário rodar migration nova para esta versão.
- A exclusão de temporada já é suportada pelo schema existente:
  seasons -> rounds -> matches -> predictions usam ON DELETE CASCADE.
- As políticas RLS da v1.2 já permitem DELETE em seasons apenas para administradores.

Para atualizar o site:
1. Substitua o projeto pela v1.3.
2. Mantenha suas Environment Variables na Vercel:
   VITE_SUPABASE_URL
   VITE_SUPABASE_PUBLISHABLE_KEY
3. Faça o novo deploy.

Novos participantes:
- Continue criando usuários manualmente em Authentication > Users no Supabase.
- Use o padrão usuario@champions-bolao.app.
- Exemplo: loia@champions-bolao.app -> login no site: loia.
- Não existe limite fixo de participantes no frontend.
